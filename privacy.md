API Sniffer Pro – Privacy Policy

API Sniffer Pro processes network request data (method, URL, headers, and optionally request/response body) solely within the user’s browser. No data is collected, transmitted, or stored on external servers. All captured data stays local to the user’s device.

Data collected:
- Web history (page URLs and API request URLs)
- User activity (API requests, responses)

Purpose of data use:
- To provide API request debugging and inspection tools.

We do not:
- Sell or share data with third parties.
- Collect personally identifiable information.
- Use the data for any purpose other than the extension’s single function.
